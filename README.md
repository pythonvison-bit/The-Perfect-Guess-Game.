
The Perfect Guess Game.

Description: A simple Number Guessing Game built in Python, where the computer randomly picks a number between 1 and 100, and the player has to guess it. After every wrong guess, a hint is given telling whether the number is too high or too low, until the correct number is found.

Features: random number generation, user input handling, and guess count tracking.

How to run: Make sure Python is installed, then run the file from the terminal using python followed by the filename.
